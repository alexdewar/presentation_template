# Imperial College London Marp presentation template

This repo contains a [Cookiecutter] recipe for generating a [Marp] presentation
template. The intention is for it to resemble [Imperial College London's PowerPoint
templates][imperial-powerpoint] and follow brand guidelines, though it is very much a work in
progress.

If you have Cookiecutter installed, you can use the template by running:

```sh
cookiecutter https://github.com/alexdewar/presentation_template
```

[Cookiecutter]: https://www.cookiecutter.io/
[Marp]: https://marp.app/
[imperial-powerpoint]: https://brand.imperial.ac.uk/document/920#/-/powerpoint-presentations
